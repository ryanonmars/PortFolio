# PortFolio v0.4.0

v0.4.0 adds agent-assisted board authoring through a local MCP adapter and an authenticated integration API. Existing boards, attachments, and manual editing workflows are retained.

## New

- **Offline board generation:** generate and validate editable board JSON with three MCP tools or the local CLI. No running server, API URL, or token is required. Review and import the result manually in PortFolio.
- **Connected board access:** browse saved boards, devices, ports, network entries, connections, and layout through scoped read-only or read/write API tokens.
- **Reviewed new-board creation:** validate proposals, inspect the canonical preview, then apply the explicitly approved result with durable idempotency receipts.
- **Version-checked editing:** submit an atomic batch of supported commands against the board's current version. Conflicts protect concurrent edits.
- **API token management:** create named tokens with optional expiry, view usage information, and revoke them under Settings → API Tokens. Secrets are shown once; only digests are stored.
- **Standalone MCP download:** compiled adapter and CLI for Node24, with a locked dependency manifest. No full application checkout or TypeScript build is needed.
- **Public setup guides:** Docker and source installation, private deployment, backups/recovery, MCP/API reference, and contributing guidance.

The adapter does not include an LLM, parse Excel/PDF source documents, access client files through MCP tools, scan networks, or control equipment. An agent uses its own authorized document/file tools. Connected writes require review; successful validation alone does not authorize apply.

## Upgrade and recovery

Back up before updating. Keep the SQLite snapshot **and** its adjacent `.sqlite.attachments/` directory together, then change the deployment's `IMAGE_TAG` to `v0.4.0` and run:

```sh
docker compose pull
docker compose up -d --wait
```

Migration009 adds hashed integration token records and proposal/retry tables at startup. Existing board documents and attachment storage are unchanged. Keep the prior image and matching complete backup; rollback means restoring that backup into a new empty data directory.

## Scope and limits

PortFolio remains a private, self-hosted documentation application. Tokens inherit existing shared administrator access; per-board ACLs and multi-user sharing are not introduced. Connected mode defaults to HTTPS. Private HTTP requires explicit opt-in on both server and adapter. No public tunnel or forwarding is configured automatically.

MCP attachment transfer, source-document parsing, destructive commands, and existing-board bulk diff/merge are outside this release. External edits do not join an already open browser's local Undo history; reload saved state after resolving unsaved changes.

The repository currently has no license file; this release does not introduce a license.
